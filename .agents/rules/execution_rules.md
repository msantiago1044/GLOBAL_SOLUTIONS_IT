# Reglas de Ejecución y Flujo de Trabajo

1. **NO REALIZAR PRUEBAS EN GOOGLE NI EN NAVEGADORES EXTERNOS**:
   - No ejecutar `browser_subagent` ni herramientas de prueba de navegador.
   - No levantar servidores locales ni procesos en segundo plano para testing en navegador.

2. **GIT PUSH AUTOMÁTICO**:
   - Cada vez que se realicen mejoras, correcciones o cambios en el código, ejecutar siempre `git add`, `git commit` y `git push` hacia el repositorio remoto.

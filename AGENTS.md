# Estándares de Código y Arquitectura - GLOBAL_SOLUTIONS_IT

## Reglas Obligatorias
- TypeScript estricto sin tipos `any`.
- Manejo explícito de errores y validación de esquemas con Zod.
- No incluir secretos, tokens ni variables de entorno en el código.
- Cada función debe tener una sola responsabilidad y nombres semánticos.

## Evidencia y Pruebas
- No modificar archivos fuera del alcance del commit.
- El código debe compilar sin advertencias antes de confirmar.

## Flujo de Entrega y Git
- SIEMPRE hacer commit y push a la rama remota al finalizar cualquier tarea o cambio validado, sin requerir confirmación interactiva adicional del usuario.
